IA en la Nube · Lección 03

¿Qué diferencia de nivel de abstracción hay entre usar GPUs en bruto (IaaS) para IA, una plataforma de ML gestionada (PaaS), y una API de modelo totalmente gestionada, en términos de cuánto control y cuánta responsabilidad operativa asume el usuario?

Con IaaS el usuario gestiona prácticamente todo (sistema operativo, drivers, framework), con PaaS el proveedor gestiona más infraestructura dejando al usuario enfocarse en el modelo y los datos, y con una API totalmente gestionada el usuario solo envía peticiones sin gestionar nada de la infraestructura subyacente
Los tres niveles (IaaS, PaaS, API gestionada) ofrecen exactamente el mismo nivel de control y responsabilidad operativa para el usuario, sin ninguna diferencia real entre ellos
Usar IaaS para IA siempre es más simple operativamente que usar una API totalmente gestionada, siendo lo contrario de lo que realmente ocurre en la práctica
Solo es relevante esta distinción de niveles si la organización tiene exactamente un único caso de uso de IA en total

IA en la Nube · Lección 03

¿Por qué un equipo sin experiencia previa en gestión de infraestructura de GPU probablemente preferiría empezar con una API de modelo totalmente gestionada, en vez de intentar configurar directamente instancias IaaS con GPUs en bruto?

Pista: configurar y mantener correctamente instancias con GPU en bruto (drivers, frameworks, optimización) requiere conocimiento técnico específico que ese equipo sin experiencia previa probablemente no tiene todavía; una API totalmente gestionada abstrae por completo esa complejidad técnica, permitiendo al equipo enfocarse directamente en integrar la capacidad de IA en su aplicación sin esa curva de aprendizaje adicional.
