¿Cuál es la diferencia principal entre un ConfigMap y un Secret?
No hay diferencia, son lo mismo con otro nombre
El Secret está pensado para datos sensibles (contraseñas, tokens); el ConfigMap para configuración normal
El ConfigMap solo funciona con bases de datos
El Secret solo puede tener un valor
Completa el tipo de recurso para guardar variables de configuración no sensibles.
apiVersion: v1 kind: metadata: name: config-app data: ENTORNO: "produccion"
¿Cómo se usa normalmente un ConfigMap o Secret dentro de un Pod?
Se copian manualmente con kubectl cp
Como variables de entorno o archivos montados en el contenedor
No se pueden usar dentro de un Pod
Solo se pueden leer desde fuera del cluster
Escribe el comando para crear un Secret llamado db-pass a partir del literal password=1234.
kubectl create secret generic NOMBRE --from-literal=clave=valor
