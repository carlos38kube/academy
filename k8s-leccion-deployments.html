Kubernetes desde cero · Lección 3
¿Para qué sirve un Deployment?
Para exponer un Pod a internet
Para gestionar réplicas de Pods y mantenerlos corriendo
Para guardar contraseñas de forma segura
Para crear un volumen de almacenamiento
Completa el campo para que el Deployment mantenga siempre 3 copias del Pod.
spec: : 3 selector: matchLabels: app: mi-app
Si uno de los Pods de un Deployment se cae, ¿qué pasa?
El Deployment se detiene por completo
El Deployment crea automáticamente un Pod nuevo para reemplazarlo
Hay que reiniciar el cluster
No pasa nada hasta que lo reinicies manualmente
Escribe el comando para escalar un Deployment llamado mi-app a 5 réplicas.
kubectl scale deployment NOMBRE --replicas=N
