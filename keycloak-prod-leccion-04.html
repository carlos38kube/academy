Keycloak en Producción · Lección 04

¿Qué diferencia principal hay entre ejecutar Keycloak en modo 'desarrollo' (start-dev) y ejecutarlo correctamente configurado en modo 'producción' (start)?

El modo desarrollo usa configuraciones simplificadas y relajadas (como una base de datos en memoria y HTTP sin cifrar) pensadas para pruebas rápidas, mientras el modo producción requiere configurar explícitamente una base de datos real persistente, HTTPS, y otros aspectos de seguridad antes de poder arrancar correctamente
El modo desarrollo y el modo producción de Keycloak son exactamente equivalentes en todos los aspectos, sin ninguna diferencia real de configuración entre ellos
Solo es relevante esta distinción entre modos si la instalación de Keycloak tiene exactamente un único usuario en total registrado
El modo producción de Keycloak elimina por completo la necesidad de tener cualquier tipo de base de datos configurada para el servidor

Keycloak en Producción · Lección 04

¿Por qué usar la base de datos en memoria del modo desarrollo de Keycloak en un entorno de producción real sería problemático, considerando qué pasaría con los datos de usuarios al reiniciar el servidor?

Pista: una base de datos en memoria pierde completamente todos sus datos cada vez que el proceso del servidor se reinicia o se apaga; en un entorno de producción real, eso significaría perder todos los usuarios registrados, sus credenciales y toda la configuración del Realm cada vez que el servidor se reiniciara por cualquier motivo, algo completamente inaceptable para un sistema de identidad real en uso activo por usuarios reales.
