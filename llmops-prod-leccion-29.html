¿Qué capacidad adicional tiene un 'agente' LLM, comparado con una aplicación de LLM simple que solo genera texto en respuesta a un prompt?

Puede decidir de forma autónoma qué herramientas externas invocar (como buscar en internet, consultar una base de datos, ejecutar código) para completar una tarea compleja de múltiples pasos
Un agente LLM elimina por completo la necesidad de tener un modelo LLM generando texto en algún momento del proceso
Solo puede invocar exactamente una única herramienta externa en toda su ejecución
Requiere que el usuario especifique manualmente cada paso exacto que el agente debe seguir

LLMOps en Producción · Lección 29

¿Por qué dar a un agente LLM en producción acceso sin restricciones a herramientas potencialmente destructivas (como eliminar archivos o ejecutar transacciones) representa un riesgo mayor que el de una aplicación LLM que solo genera texto?

Pista: mientras una aplicación LLM simple solo genera texto que un humano luego interpreta, un agente con acceso a herramientas puede ejecutar acciones reales de forma autónoma; si el modelo razona incorrectamente sobre cuándo o cómo usar una herramienta destructiva, esa decisión errónea se traduciría en un daño real al sistema, no solo en una respuesta de texto equivocada sin consecuencias directas.
