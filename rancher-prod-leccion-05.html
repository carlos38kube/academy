¿Qué vista central ofrece el dashboard principal de Rancher al entrar por primera vez, antes de seleccionar un cluster específico?

Una vista general de todos los clusters gestionados (management y downstream), con su estado de salud, versión de Kubernetes, y alertas relevantes de cada uno
Solo muestra el código fuente de las aplicaciones desplegadas en los clusters
Solo funciona si el usuario tiene exactamente un único cluster gestionado en total
Requiere conocer previamente el nombre exacto de cada cluster antes de poder verlos

¿Por qué tener una vista consolidada del estado de salud de todos los clusters en un solo dashboard ayuda a un equipo de plataforma a detectar rápidamente cuál cluster específico necesita atención entre muchos?

Pista: en vez de tener que entrar individualmente a cada cluster para verificar su estado, el equipo puede identificar de un vistazo cuál cluster específico entre muchos tiene un problema, priorizando su atención de forma mucho más eficiente.
